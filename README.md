# EcoRuta móvil

Prototipo académico de aplicación móvil desarrollado con Python, Flet y SQLite.

Incluye:
- Registro e inicio de sesión de usuarios.
- Acceso independiente para administrador.
- Panel administrativo con usuarios, reportes y estados.
- Edición de perfil de usuario.
- Cierre de sesión.
- Reportes con fotografía, GPS, fecha/hora, autor y estado.
- Consulta de reportes propios para cada usuario.
- Consulta de todos los reportes desde administración.
- Cambio de estado del reporte: Pendiente, En revisión y Atendido.
- Apertura de coordenadas en Google Maps.
- Chat local y posibilidad de compartir reportes.
